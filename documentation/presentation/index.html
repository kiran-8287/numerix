01 — MOTIVATION

Numerical answers are
earned, not assumed.

A formula can be exact on paper and unreliable on a computer.

Finite precision, conditioning, stopping rules and invalid inputs all affect a computed answer. A small residual can still hide a poor root position; a fast method can converge to the wrong result or fail on a difficult case.

NUMERIX aims to make these choices visible in a small C library: algorithms return status and work information, while supporting systems recommend methods, manage execution and analyze results.

01

Convergence

Did the method make progress under its stopping rule?

08 — CONCLUSION
N∑

A numerical library
is more than its fastest method.

NUMERIX combines seven numerical modules with a public C interface, method recommendation, managed execution, diagnostics and heuristic discovery. Its current test suite exercises algorithms, integration paths, edge behavior, accuracy and installed consumers.

Root measurements show competitive paired timings on several tested routes, with accuracy and completion differences that matter. They do not establish a universal winner. Six module studies, method-specific memory and tolerance-sweep measurements remain unfinished.

Build carefully. Measure fairly. Report what the evidence supports.
